# Storage Drivers

Kuzzle talks to its database through a storage driver, an npm package selected in the configuration
(`services.storageEngine`). The Elasticsearch 7 and 8 drivers come with Kuzzle 2; the others are installed next to it.
See [Data storage](/core/2/guides/main-concepts/data-storage#storage-drivers) for how drivers work, and
[Write a storage driver](/core/2/guides/write-storage-drivers/) to support another engine.
